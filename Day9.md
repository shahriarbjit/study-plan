# Day 9 - AI for Code Review, Debugging & Architecture

Date: 2026-05-07
Duration target: 60-90 minutes
Rule: Use AI as a tool — but always verify its output and note where it is wrong
Mode: Prefill (fill this before AI review)

## Day 9 Goal
Learn to use AI as a code reviewer, a debugging partner, and an architecture critic. The key skill today is asking AI the RIGHT question — not just "is this good?" but "what specifically is wrong with X dimension of this code?"

## Session Plan (Time-boxed)

1. AI code review exercise on a real file (25 min)
2. Rubber-duck debugging with AI (15 min)
3. AI architecture critique exercise (15 min)
4. Find one case where AI gave wrong/outdated output (10 min)
5. Reflection and self-rating (10 min)
